# انبار

نرم‌افزار انبار امانی، سفارش و تسویه‌ی سندلوس با شرکت‌های طرف قرارداد.
قیمت و موجودی همه‌ی کالاهای سایت ووکامرس شرکت‌ها را زنده می‌خواند و برای هر کالا معلوم می‌کند
در هر ساعت روی سایت چه قیمتی داشته؛ مبنای تسویه‌ی دقیق آخر ماه.

وضعیت: فاز ۱ (پایه و اتصال)، فاز ۲ (سفارش، دریافت روزانه، موجودی، ورود از اکسل) و فاز ۳ (مرجوعی، صورت‌حساب ماهانه، انبارگردانی) آماده است. تصمیم‌ها و فازها: [docs/decisions.md](docs/decisions.md).

## امتحان سریع (نسخه‌ی نمایشی)
```bash
npm install
npm run demo
```
بعد http://127.0.0.1:8080 — ورود با `demo` / `demo-1234` (مدیر) یا `ali` / `demo-1234` (ادمین).
سه فروشگاه ووکامرس آزمایشی کنار نرم‌افزار راه می‌افتند و قیمت‌هایشان هر چند ثانیه عوض می‌شود.

## راه‌اندازی روی سرور (Docker)
یک فایل `.env` کنار `docker-compose.yml` بسازید:
```
APP_SECRET=یک-رشته‌ی-تصادفی-بلند
PUBLIC_URL=https://anbar.example.ir
MANAGER_USERNAME=admin
MANAGER_PASSWORD=رمز-قوی
MANAGER_NAME=مدیر
```
```bash
docker compose up -d
```
جلوی آن nginx یا Caddy با HTTPS بگذارید. دیتابیس در volume با نام `anbar-data` است؛ از آن نسخه‌ی پشتیبان بگیرید.
`APP_SECRET` را عوض نکنید (کلیدهای API ووکامرس با آن رمز شده‌اند).

## وصل کردن سایت یک شرکت
1. در وردپرس سایت: ووکامرس ← تنظیمات ← پیشرفته ← REST API ← افزودن کلید با دسترسی «خواندن».
2. در انبار: شرکت‌ها ← شرکت جدید ← آدرس سایت و کلید را بدهید ← «بررسی اتصال» ← ثبت.
3. (پیشنهادی) افزونه‌ی «اتصال انبار» را از صفحه‌ی شرکت دانلود و در وردپرس نصب کنید تا هر تغییر قیمت همان لحظه برسد.
